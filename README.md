# KisanSetu v4

## Language buttons fixed
English, हिंदी, and मराठी now work and translate:
- Main heading and description
- Service section
- All service card titles/descriptions
- Search placeholder
- Help examples
- Safety notice
- Footer/disclaimer
- Official-site buttons

The selected language is saved in the browser using localStorage.

## Run
Extract the ZIP, open the folder in VS Code, open `index.html`, then use **Open with Live Server**.
